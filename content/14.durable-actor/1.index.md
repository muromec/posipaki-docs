# A durable actor

An actor whose state is the fold of a durable record log, and whose only words are whether it took a request.

```ts
type FilterResult<E = string> = { pass: true } | { refuse: E };

interface RecordSpec<S, R, Q, E = string> {
  filter(state: S, request: Q): FilterResult<E>; // may it go on
  map(state: S, request: Q): R;                  // the record it becomes
  reduce(state: S | null, record: R): S;         // one record onto the fold
  diff(before: S | null, after: S): R;           // the way back
}
```

- **filter gates map.** A `refuse` writes nothing; a `pass` means `map` is called exactly once.
- **map is pure.** Same state, same request, same record — twice. A record's moment and ids belong to whoever
  builds the request, so a replay builds what the live run built.
- **reduce is the fold.** A journal in, the state out; `reduce(null, r)` is the first step.
- **diff inverts reduce.** `reduce(before, diff(before, after))` is `after`, for every adjacent pair — which
  forces the state to remember what its records said.

A caller says `ADD_RECORD`, `ATTACH` or `DETACH`, and hears `RECORD_ACCEPTED` or `RECORD_REJECTED`. There is no
third word: a process that cannot go on — its source went, a record would not fold — dies with the reason instead
of answering, and a caller waiting on it hears that it ended.

## Live demo

Three boards. The first owns the log: it filters what it is asked and writes the record. The second follows it
and defers: it says nothing until the record has come back. The third follows the second and guesses: it shows the
change at once, and if the authority refuses the guess it folds back and says so.

Pick a figure, then click a box to place it there. To clear a box, click it again. Two of one figure on a board
clear the whole board. Between the boards are four wires — records one way, requests the other — each carrying,
slow or cut: a wire shows what is inside it while a message is there, and a board behind a cut one stops until the
wire carries again, when it is re-attached from the state it finds.

The implementation is [`posipaki/packages/durable-actor`](https://github.com/muromec/posipaki/tree/main/packages/durable-actor);
the widget in this page runs that package.
