# Reflection

> Every spawned process exposes a `$reflection` handle — callable methods that
> let you inspect and drive a live actor from outside its message loop.

## Defining methods

Add methods with the `$reflectionMethods` config field. They appear on the
process handle as `proc.$reflection`:

```ts
import { defineActor } from "posipaki";

const counter = defineActor({
  $reflectionMethods: {
    getCount() {
      return this.state.count;
    },
    reset() {
      this.state.count = 0;
    },
  },
  setup: () => ({ count: 42 }),
  handlers: {},
});

const proc = await counter.spawn(null);
await proc.ready();

proc.$reflection.getCount(); // 42
proc.$reflection.reset();
proc.$reflection.getCount(); // 0
```

## `this` is the actor context

Inside a method, `this` is the full `ActorContext` — `this.state`, `this.name`,
`this.id`, `this.$child`, `this.emit`, `this.exit`, plus any decoration a plugin
added.

```ts
$reflectionMethods: {
  describe() {
    return { name: this.name, children: Object.keys(this.$child) };
  },
},
```

## Typing

Your own `$reflectionMethods` are typed automatically from the config.
`proc.$reflection` is typed as your methods **and** every method a
plugin adds. Plugin-provided methods are typed via declaration merging on
`ActorReflection`; see the [Plugins](/plugins/) page for that pattern.

## Plugins add methods too

`mergeConfigs` deep-merges `$reflectionMethods`, so several plugins can each
register their own namespaced methods. See [Plugins](/plugins/).

```ts
import { mergeConfigs, type ActorPlugin } from "posipaki";

const counters: ActorPlugin = (config) =>
  mergeConfigs(config, {
    $reflectionMethods: {
      "counters.get"() {
        return this.state.count;
      },
    },
  });
```

## Reaching children

Every process handle has `$reflection` — including children. The handle
returned by `fork` is typed, so a child's methods are directly callable:

```ts
async setup() {
  const worker = await this.fork(workerActor);
  return { worker };
},
// ...
this.state.worker.$reflection.getCount();
```

`this.$child` and `this.ctx.children` hold `AnyProcess`, whose `$reflection` is
typed as `{}` — cast to reach a specific method:

```ts
const child = this.$child["main:worker"];
(child.$reflection as { getCount: () => number }).getCount();
```

The [Introspection](/introspection/) plugin is the bundled consumer — it walks
`$reflection` on children to build a live process tree.
