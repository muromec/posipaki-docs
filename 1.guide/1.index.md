# Quick Start

> Actor processes for JavaScript, built on generator functions.

## Install

::pm-install{name="posipaki"}

## Your first actor

```ts [counter.ts]
import { defineActor } from "posipaki";

const counter = defineActor({
  setup: () => ({ count: 0 }),
  handlers: {
    POKE(msg, sender) {
      this.state.count++;
    },
  },
});

const proc = await counter.spawn(null);
await proc.ready();
proc.send({ type: "POKE" }); // proc.state.count === 1
```

A process receives messages, updates its own state, and sends messages back.
It can also fork children, pause/resume, and exit on its own terms.
